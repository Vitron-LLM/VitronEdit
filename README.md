# Vitron-E

## Universal Visual Editing across Images, Videos, and 3D Scenes

This repository contains the source code for the [Vitron-E project page](https://vitron-llm.github.io/Vitron-E/).

Vitron-E is a unified framework for image, video, and 3D scene editing, combining cross-modal editing transfer with geometry-aware post-training.
